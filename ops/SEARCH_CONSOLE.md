# Google Search Console 登録手順（オーナー向け・約10分）

目的: Google 検索での表示回数・検索キーワードを無料で確認し、sitemap を送信する。
匿名性: サイトのブランド用 Gmail で登録してください（個人のアカウントは使わない）。確認コードはサイトに公開されますが、アカウント情報は含まれません。

## オーナーがやること
1. ブランド用 Gmail で https://search.google.com/search-console を開く。
2. 「プロパティを追加」→ **URL プレフィックス** を選び、`https://japan-toolkit.github.io/` を入力。
   （「ドメイン」方式は DNS 設定が必要で github.io では使えません。）
3. 確認方法の一覧から **HTML タグ** を選び、表示された
   `<meta name="google-site-verification" content="……" />` をコピー。
   ※ まだ「確認」ボタンは押さない。
4. このセッションにタグをそのまま返信してください（例:「確認コード: <meta …>」）。

## Claude がやること
5. `ops/google-site-verification.txt` にコードを書き、`build/build.py` で再ビルド（トップページ `/` の `<head>` にだけタグが入る）。
6. 全ページ確認 → 「反映してOK」をもらって main に反映。
7. 反映後、オーナーが Search Console で「確認」を押す。

## 確認できたら（オーナー）
8. 左メニュー「サイトマップ」に `sitemap.xml` を入力して送信。
9. 数日〜2週間でデータが出始めます。週1回「検索パフォーマンス」を見るだけで十分です。

## 注意
- 確認タグは消さないこと（消すと所有権の確認が外れます）。build.py は txt ファイルがある限り毎回タグを出力します。
- 費用はかかりません。Cookie やトラッキングは追加されないため、プライバシーポリシーの変更は不要です。
